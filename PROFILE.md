## APIs

- **QRCodeCrafter API** — REST API for static QR generation, bounded bulk generation, and managed dynamic QR redirects. Public by default with optional API key and dynamic-QR bearer capability tokens. (`https://qrcodecrafter.com/.netlify/functions/generate-qr`)

> OpenAPI 3.0.1 (JSON and YAML) publicly hosted with x-agent-workflows and x-agent-recipes extensions. Agent-native via llms.txt, ai.txt, and WebMCP. Important: the WebMCP surface is a browser-runtime/in-page MCP (registered via document.modelContext/navigator.modelContext) exposing tools generate_qr and generate_bulk_qr — NOT a hosted remote MCP server (no /sse or streamable-HTTP endpoint published), so no MCP property is emitted. A legacy ai-plugin.json (OpenAI plugin manifest, auth: none) is also served at /.well-known/ai-plugin.json. No AsyncAPI, GraphQL, or public Postman collection found. Free public static QR generation, rate-limited by rendering cost; optional issued API keys for higher volume.
